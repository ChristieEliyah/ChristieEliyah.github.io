📐 设计文档摘要

项目定位：UE5 FPS 训练靶场 Demo，参考 COD 新手教程关卡设计，纯蓝图开发。从 XL_FPSPack 资产包基础上进行系统化整合与定制，覆盖输入层→逻辑层→表现层的完整链路。

设计目标：

  • 即时命中（Hitscan）+ 完整击中反馈链路
  • 开火 / 瞄准 / 换弹 / 弹药管理
  • 分层动画系统（BlendSpace 无缝过渡）
  • 武器基类 + 蓝图接口，可扩展架构

核心系统概览：

系统模块核心内容
玩家角色Character → BP_FPSPlayer，5 种移动状态、FOV 切换、鼠标灵敏度控制
武器系统BP_WeaponBase 基类 + BP_VIRTUS 突击步枪（300 BLK），弹匣 30 发，射速 600 RPM，换弹 2.5s
输入系统6 个 Enhanced Input Action + WASD 鼠标全映射
命中检测LineTrace 射线 → 物理材质判定 → 多表面响应（血液/混凝土/玻璃/金属/木头/水等）
靶子系统BP_TargetDummy，100 HP，Timeline 击倒动画 + 自动复位
动画系统玩家 ABP + 武器 ABP + 2 个 BlendSpace + 换弹 AnimNotify
弹壳系统物理抛壳 + 碰撞音效 + 自动销毁
HUDHealth_HUD 血量显示 + 弹药 HUD_Ammo 实时弹药计数 + 准星 Widget

技术架构：分层设计 — Input 层（Enhanced Input）→ Controller 层（PlayerController）→ Character 层（BP_FPSPlayer + 状态机）→ Weapon 层（BP_WeaponBase → BP_VIRTUS）→ Feedback 层（VFX / SFX / 物理）。蓝图接口 BI_Fire 实现武器与玩家的解耦通讯。

项目资产统计：933 个文件 | 9 个蓝图类 | 2 个接口 | 3 个枚举 | 38 套骨骼动画 | 35 个 Niagara VFX | 8 个 Sound Cue | 31 个 Sound Wave
