UE5 射击靶场 Demo

个人项目 · UE 5.8 纯蓝图 · 当前版本 v0.42

一把 MCX VIRTUS 突击步枪，全自动 Hitscan 射击，四种表面命中反馈，一个能自己加球的靶场，一个计分计时面板。做到 v0.42，能完整走通「瞄准—开枪—命中—补弹—计数」这条链路。

目标很朴素：手感别别扭。开枪要有反应，命中要有反馈，换弹要看得懂。

三个系统

3C：角色 / 相机 / 操控

角色从 Character 派生，相机和手臂骨骼网格直接挂在默认组件上，位移交给 CharacterMovement，没有自己写移动逻辑。

相机的 FOV 用 FInterpTo 插值收窄，不硬切。硬切看着像镜头跳了一下，玩家会以为卡帧。开镜灵敏度单独给一个变量，跟着瞄准状态走——不这么做，放大之后手感会突然变快，压枪全乱。

操控分三档速度：步行 265、瞄准移动 400、冲刺 600。切换靠一个四状态枚举（Idle / Walk / Sprint / ADS）改写 MaxWalkSpeed，不用叠 buff，也不用改输入映射。输入统一走 Enhanced Input，一张 IMC 管七个动作：Fire、Aim、Move、Look、Reload、Run、AddAmmo。

武器

武器在 BeginPlay 里生成后挂到手臂 Socket，而不是提前摆在关卡里——这样换枪不用动关卡。

基类 BP_WeaponBase 只放逻辑：开火、射线、弹药、换弹、抛壳。子类 BP_VIRTUS 只放数据和资产：网格、动画蒙太奇、瞄具、弹匣容量。

这么拆是因为加第二把枪的时候，我只想继承基类、换资源，不想碰玩家代码。玩家侧只认 BI_Fire 接口里的 StartWeaponFire，手里拿的是什么枪它不关心。

换弹的弹药结算挂在 AN_Reload 这个 AnimNotify 上，没有另写计时器。动画播到那一下才结算弹匣，以后改动画时长，逻辑自动跟着走，不用两边对时间——这是上一版最烦的地方。

射击反馈

开火是 Hitscan：从相机位置往前打一条 LineTrace（Visibility 通道，10000 单位），命中后按物理材质分流。

目前做了四种：血、泥土、金属、木头。每种配自己的特效、音效和弹孔——金属和木头用专用贴花，血不加贴花，泥土走默认弹孔。做四种不是凑数，是这四类在靶场里都会被打到，反馈不一样才看得出打中了什么。

命中之后还要判断打的是什么：小球、加球按钮、补弹箱，还是环境。这里是 Cast 链，顺序是球 → 按钮 → 补给箱 → 环境兜底。老实说这条链我不满意：Cast 到具体类型意味着加一种新目标就得回来改武器，耦合太重。正确做法是让被打的物体实现同一个接口，武器只调接口、不认类型。

靶场怎么玩

场上小球数量由加球按钮控制：打一下按钮多一个球，打掉一个立刻补一个，数量守恒。生成点是管理器位置加上一个随机方向乘半径，所以球不会全落在同一条线上。

补弹两条路：打补给箱，或者走近按 F。两种都直接把弹匣补到 30、备弹补到 180。补给箱现在只有碰撞和逻辑，外观还没做。

右上角显示弹药和计分。计分是打中球加一分，计时从按下开始按钮算起。

现在的问题

  • 只有一把枪，没有切换。基类已经能扩展，但没做第二把来验证。
  • 补给箱没有外观，站近了看不出那是能打的东西。
  • Cast 链耦合，加新目标要改武器（上面说过）。
  • 靶场只有小球这一种玩法，练不了别的。

接下来

v1.00 往训练模式走：几种不同的靶（固定、移动、限时），命中率和反应时间统计，难度递进。做完才能说这是「训练靶场」而不是「打球的场景」。

v2.00 加滑铲和蹲下，再做一个 COD 式的新手教学白盒关——有引导、有节奏、有终点，用来练关卡而不是练枪。
